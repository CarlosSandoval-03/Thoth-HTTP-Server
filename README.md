# Thoth-HTTP-Server

## Getting Started

### Prerequisites

- [C Compiler](https://gcc.gnu.org/)
- [Clang (format, tidy)](https://clang.llvm.org/)
- [Make](https://www.gnu.org/software/make/)
- [Bear](https://github.com/rizsotto/Bear)

### Installing

```bash
git clone https://github.com/CarlosSandoval-03/Thoth-HTTP-Server
make
```
